# A기업 리서치 주피터 사용 안내

## 시작 방법

1. A기업_주피터_패키지.zip을 압축 해제합니다. 폴더 구조를 유지하세요.
2. 터미널에서 압축 해제한 OpenResearch_Jupyter 폴더로 이동합니다.
3. 현재 사용할 Python 환경에 아래 패키지를 설치합니다.

    python -m pip install -r requirements-notebook.txt
    python -m jupyterlab

4. notebooks/A기업_리서치_탐색.ipynb를 열고 Python 3 커널을 선택합니다.
5. 위에서부터 셀을 실행합니다. 버전 메뉴와 산업/기술 주장 버튼으로 탐색합니다.
6. 근거의 전체 원문 펼치기를 누르면 포함된 로컬 원문을 볼 수 있습니다.

이미 Jupyter가 설치되어 있다면 노트북 설치 셀의 %pip 주석을 해제해 ipywidgets만 설치할 수 있습니다.
VS Code에서도 Jupyter 확장을 통해 같은 노트북을 실행할 수 있습니다.
위젯이 표시되지 않으면 커널 환경을 확인하고 다시 시작하거나 정적 보기 셀을 실행하세요.
정적 보기는 VERSION=1/2, CLAIM=C01/C02 값을 바꿔 실행합니다.

## 포함 내용

- 실행 가능한 ipynb 노트북과 Python 조회 모듈
- A기업 최초/수정 JSON 및 합성 원문 두 개
- 공통 주장·근거·버전 검사 모듈
- 원본 파일을 덮어쓰지 않는 메모리상 버전 변경 실습

API 키, Neon DB, Solar, 별도 웹 서버는 필요하지 않습니다.
인터넷은 최초 패키지 설치 시에만 필요하며 자료 조회는 로컬에서 동작합니다.
실제 시장 분석·예측이나 공유·승인 기능은 포함하지 않습니다.
휴대용 ZIP은 노트북 실행에 필요한 파일만 담았으며 전체 OpenResearch Agent 소스를 대체하지 않습니다.
기존 저장소에도 동일한 notebooks 폴더와 agent/notebook_viewer.py를 추가했습니다.
