# v0.9.1-connect-help — 연결 도우미 (사용자 친화)

- 자료형이 다른 포트를 이으려 하면 도우미 창: 왜 안 되는지 쉬운 말로 설명, ① 받는 노드에 맞는 자료를 만드는 노드 「놓고 잇기」(캔버스에 이미 있으면 「잇기」), ② 보내던 결과를 받을 수 있는 노드 「보내기」. 준비 중(미연결) 노드는 그렇다고 알림
- 「놓고 잇기」는 새 노드에 필요한 앞 노드까지 자동 배치(캔버스에 있는 노드 재사용), 배치 후 화면 맞춤
- 노드 설정 탭: 비어 있는 필수 입력 안내 + 「필요한 앞 노드 채우기」
- 실행 전 확인 목록: 쉬운 말 + 바로 고치는 버튼(앞 노드 채우기 / 준비 중 노드 빼기 / 잘못된 연결선 지우기), 오류 코드는 작게
- 입력 칸을 먼저 눌렀을 때 무엇을 받는 칸인지 안내, 한국어 조사(은/는·이/가·을/를·과/와·으로/로) 자동
- 변경: web/app.js, web/app.css (서버 변경 없음)
- 시험: 76개 통과, 헤드리스 브라우저 3개 시나리오(사용자 화면 N01·N06·N03 재현 → 버튼 3번으로 실행 성공) 콘솔 오류 0
