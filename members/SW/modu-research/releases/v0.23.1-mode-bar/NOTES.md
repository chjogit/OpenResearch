# v0.23.1-mode-bar — 쉬운 화면 / 전문가 모드를 한눈에 구분

- 두 화면 맨 위에 같은 모양의 **모드 띠**: 「● 쉬운 화면 | ◆ 전문가 모드」 스위치, 지금 화면이 켜져 있음, 오른쪽에 지금 모드 설명.
- 쉬운 화면 = 밝은 주황 띠(아래 주황 선), 전문가 모드 = 짙은 남색 띠(아래 파란 선) + 도구줄 왼쪽 「전문가 모드」 배지.
- 넘어갈 때 보던 것을 들고 감: 쉬운 화면에서 답을 보는 중이면 전문가 모드가 그 답의 단계를 열고(#run=), 전문가 모드에서 실행 결과가 있으면 쉬운 화면이 그 답을 엶(#answer=).
- 기존의 「전문가 모드」 버튼(쉬운 화면 메뉴)과 「← 쉬운 화면」 링크(전문가 도구줄)는 모드 띠로 옮김.
- 계산·API 변경 없음. 시험 212개(신규 1).
