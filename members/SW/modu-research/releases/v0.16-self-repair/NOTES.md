- mrn/repair.py: 보류 이유 코드별 대체안 제안 → 사람이 고른 것만 적용한 새 문서 → 새 실행 (원래 실행은 그대로)
  - 공식 원문 자료판이 기준 날짜보다 새것(cutoff_before_corpus) → 그 날짜에 접수돼 있던 사업보고서의 공시 API 재무(T11)로 대체 [근거 수준 낮아짐 표시]
  - 기준 날짜에 아직 없던 연도(N01 「접수된」 사유) → 이미 나와 있던 연도로 [더 오래된 연도 표시]
  - 가격 이력 부족(too_short) → 520거래일로
  - 공시·뉴스 없음(T08 no_rows) → 365일로
  - 원문 문단 대조 불가(T02 held, 선택 입력일 때만) → 대조 없이 [원문 대조 생략 표시]
  - 자료 자체가 없음(T06·T07 no_rows) → 그 자료가 꼭 필요한 계산만 빼고 나머지로 답함 (숫자를 대신 채우지 않음)
  - 환율·금리 영향(N06)에 거시 자료 미연결 → 연결
  - 대체안이 없으면 「아직 모르는 것」 그대로
- API: GET /api/easy/repairs/{run}, POST /api/easy/repair {run_id, ids} (감사 기록 easy.repair: 코드·근거 하향 여부)
