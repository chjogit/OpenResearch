# v0.39.3 가격 자료 자동 갱신 (PM 결정 2026-11-15, 연구용 · 재배포 계약 전)

문제: 계산용 가격 사본(Neon 공용 DB의 금융위 시세)이 2026-11-07 사본(마지막 거래일 11-05)에 멈춰, 답 카드에 「자료 마지막 거래일 2026-11-05」.
해결: 사본에 **한국투자증권(KIS) 일별 시세로 빈 날을 채운 새 사본**을 만드는 도구 + 엔진이 그 행(source='kis')을 계산에 쓰도록.

## 엔진 (patch_price_src.py)
| 파일 | 내용 |
|---|---|
| mrn/price_src.py (새) | `ok(src)`: 금융위(fsc)는 늘, kis는 `MODU_PRICE_KIS`≠0 일 때(기본 켬). `pick()`: 같은 날 둘 다 있으면 금융위 우선 |
| mrn/market.py | price_series 가 `pick` 사용 · 출처에 「+ 한국투자증권 일별 시세(kis) n거래일 보충(연구용·재배포 계약 전)」, `kis_rows` |
| mrn/edi_market.py · reaction.py(2곳) · prob.py | 「source == 'fsc'」 → `ok(source)` |
- 시험 4개(tests/test_v0393_price_src.py) · 전체 593개 통과(건너뜀 1) · 되짚기 통과.
- 비교기업 가격(peer_price_daily)은 그대로 금융위만.
- X2(KIS 시세는 감지에만)를 PM 결정으로 고침: **일별 종가는 계산 사본에 연구용으로 들어감**(출처 표시). 실시간 현재가는 여전히 답 카드에 안 넣음.

## 갱신 도구 `_tools/price_refresh/price_refresh.py`
- 원래 사본은 그대로, 새 사본 폴더 → 엔진 방식으로 다시 읽어 확인 → 마지막에 LATEST.txt 만 바꿈. 되돌리기 = LATEST.txt 를 예전 이름으로.
- 회사마다 KIS 일별 시세(원주가 `FID_ORG_ADJ_PRC=1`)의 최근 5거래일 종가를 사본 값과 **원 단위까지 대조** → 다르면 그 회사는 안 채움, 실패 20% 넘으면 아무것도 안 바꿈.
- 시가총액 = 마지막 행의 (시가총액÷종가)×새 종가(주식 수 그대로 가정). 코스피·코스닥 지수도 겹치는 날 0.1% 안일 때만.
- 바뀌지 않은 파일은 하드링크(공간 절약). 결과 기록 `last-result.txt`(키 값 없음).
- 시험 4개(test_price_refresh.py, 가짜 KIS): 채우기·대조 실패 멈춤·지수 대조·--dry/--auto.
- 실행: 바탕화면용 `_screen_jt\모두의리서치_가격갱신.bat`(직접) · `시연_열기.ps1`이 엔진을 켠 뒤 `--auto`로 뒤에서(이미 최신이면 KIS 안 부름).
