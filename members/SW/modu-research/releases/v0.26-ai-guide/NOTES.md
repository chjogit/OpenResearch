# v0.26-ai-guide — AI 길잡이 T1 (질문 통역 · 사용 안내, 기본 꺼짐)

원칙: 「AI는 길만, 숫자는 앱만」.
- 새 모듈 mrn/guide.py, mrn/guide_api.py(server.py에는 register 두 줄만 덧붙임 — v0.25 공시 반응 사전 방식과 같음).
- API: GET /api/guide/status (모델 연결 여부·이름·로컬 여부, 키는 내보내지 않음), POST /api/guide/translate {question, company, use_model}.
- 쉬운 화면 「직접 물어보기」: 알아듣지 못하면 「가까운 질문 찾아보기」(규칙, AI 아님). 모델이 연결돼 있고 「AI 길잡이 쓰기」를 켜면 AI 제안(바꾼 질문 + 가까운 카드 + 이유). 「이 질문으로 물어보기」→ 「이렇게 이해했어요」→ 사용자가 실행.
- 안전장치: 숫자(질문의 연도 제외)·매매·목표주가 표현이 든 모델 글은 버림, 카드 id는 등록부 대조, 바꾼 질문은 조립 에이전트가 다시 읽어 알아들을 때만 표시, 판단 질문은 모델을 부르지 않고 거절+재료 안내, 모델 실패 시 규칙으로.
- 표시: 「AI 작성」 배지·모델 이름·호출 수. 그 질문으로 실행한 답의 작동 원리에 「AI 모델 1회 — 질문 바꾸기에만」(run meta.guide). 감사 기록은 질문 지문만.
- 「어떻게 일하나요?」 AI 설명 갱신. README 절 추가.
- 시험 257개(신규 9 — 가짜 모델 서버로 통과·거절·실패 대체 확인). 실제 모델 연결 확인은 사용자 PC에서(local-env.cmd 설정 필요).
