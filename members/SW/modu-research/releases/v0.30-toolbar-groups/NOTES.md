# v0.30-toolbar-groups — 전문가 모드 도구 모음: 세 묶음 + 마우스 올림 설명

- 버튼 12개를 「파일(새로·예시 사례·열기·저장) / 자료 살피기(근거 지도·문서·재무·증권사 전망·표현 검사) / 실행(검증·에이전트 실행·실행·취소)」 세 묶음으로 나누고 묶음마다 옅은 색(회색·파랑·주황)과 이름표를 붙임.
- 마우스를 올리거나 키보드로 고르면 0.25초 뒤 한 줄 설명 말풍선(data-tip). 브라우저 기본 title 말풍선은 겹치지 않게 제거, 화면 읽기용 aria-description 추가.
- 창이 좁으면 도구 모음이 둘째 줄로 내려감(전에는 가로로 잘려 「취소」가 안 보였음). 900px 이하에선 묶음 이름표 숨김.
- 버튼 id·순서·동작 그대로(app.js 변경 없음). 시험 287개 통과(신규 4, tests/test_toolbar.py).
