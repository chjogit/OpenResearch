# v0.24.2-run-summary — 전문가 모드 실행 결과 요약

- 실행이 끝나면 오른쪽 패널 맨 위에 「실행 결과 요약」: 회사·기준 날짜, 분석 상태 수, 자료로 확인/계산/추정/모르는 것 수, 관점별로 노드마다 핵심 숫자 4개(나머지는 펼치기)와 아직 모르는 것, 「이 결과가 아닌 것」.
- 노드 이름을 누르면 그 노드의 결과 탭. 「요약을 글로 복사」(메모·메일용 텍스트), 「T05 보고서 취합 결과」, 「쉬운 화면 답 카드로 보기」.
- 실행 줄 오른쪽: 「결과 요약 보기」·「쉬운 화면 답 카드 →」 단추. 실행이 끝나는 순간 자동으로 요약을 보여 주고 알림.
- 요약은 쉬운 화면 답 카드와 같은 계산(/api/easy/answer)을 써서 두 화면의 숫자가 같음.
- 작동 원리 「질문 이해」: 전문가 모드에서 사람이 짠 구성은 「직접 구성」으로 표시(에이전트라고 부르지 않음).
- 다른 대화의 v0.25(공시 반응 사전) 파일(server.py, easy.js, reaction*)은 건드리지 않음. 시험 229개(신규 2, 클라우드) + 장치 전체.
