# v0.23-easy-ui-1.4 — 쉬운 화면 1.4: 세 개의 문 · 지금 어디쯤 · 작동 원리 띠 · 다음 걸음

기준: 앱 폴더 현재 상태(v0.22까지 반영된 것) 위에 화면 변경만. 계산 단계·자료·DB 표는 바꾸지 않음.

- **세 개의 문** (첫 화면): 「궁금한 것 묻기 / 내 생각 시험하기 / 근거 검증하기」 — 사람이 아니라 하려는 일로 나눔. 고른 문은 이 브라우저에 기억. 「근거 검증하기」는 확인서 넣기 + 최근 본 답 따라가기를 바로 펼침.
- **지금 어디쯤** 줄: 무엇을 할까 › 회사 › 질문 › 답 › 근거 (누르면 그 단계로).
- **질문 카드 묶음**: 지난 일 확인(사실) / 시장의 움직임(사실·관계) / 앞으로에 대한 가정(가정) — 카드마다 값 종류 칩. 문에 맞는 카드는 진하게, 나머지는 옅게(누를 수 있음). 본 카드에 「✓ 봤어요」, 회사별 「질문 9개 중 n개 살펴봄」 막대.
- **진행 화면**: 질문 이해 › 자료 찾기 › 계산 › 정리 단계 표시, 단계마다 종류 칩(원문 검색 포함).
- **작동 원리 띠** (답 카드): 질문 이해 → 자료 찾기 → 계산 → 검사 → 확인서. 실행 기록에서만 만듦(mrn/easy.py `process`). 카드 경로는 「근거 사슬」(에이전트라고 부풀리지 않음), 직접 물어보기는 「조립 에이전트(규칙)」, 원문 검색(T02)이 실제로 돌았을 때만 「RAG」. 매매 지시 표현은 numeric 규칙으로 검사해 건수 표시. **AI 모델 호출 수** 표시(현재 0회).
- **다음 걸음**: 카드별로 이어 볼 질문 2~3개 + 「내 가정 적어 보기」(전망 그림이 있을 때) + 「이 답 검증하기」.
- **어떻게 일하나요?** 화면: 다섯 단계, AI 모델 사용 여부, 10가지 성질을 겪는 자리(누르면 해당 문으로), 쉬운 말 풀이(에이전트·RAG·근거 관문·지문·근거 확인서).
- 처음 안내 3장 교체(문 → 배지 → 작동 원리).
- API: `/api/easy/cards`에 group·kind·doors·next와 groups·doors 추가, `/api/easy/answer`에 process·next 추가(기존 칸 그대로). 직접 물어보기 실행 meta에 planned_by.
