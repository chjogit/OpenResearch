# v0.23.2-mode-choice — 넘어가기 전에 1차 판단: 언제 어느 모드로?

- 모드 띠에 「언제 전문가 모드로?」(쉬운 화면) / 「언제 쉬운 화면으로?」(전문가 모드) 단추. 누르거나, 다른 모드 단추에 마우스를 올리면 안내가 열림.
  - 한 줄로 고르기: 숫자를 읽고 출처를 확인 → 쉬운 화면 / 숫자를 바꿔 보기·자료 넣기·원문 대조 → 전문가 모드.
  - 「쉬운 화면에서는 알기 어려운 것 → 전문가 모드에서 알 수 있는 것」 6줄 짝(전문가 모드에 실제로 있는 화면 이름만: 문서·재무, 증권사 전망, 표현 검사, 근거 지도).
  - 반대 방향(전문가 모드 → 쉬운 화면)도 5줄 짝.
- 모드 단추 설명 다듬음: 쉬운 화면 「질문하고 답과 근거 읽기」, 전문가 모드 「바꿔 보기·자료 넣기·원문 대조」.
- 답 카드마다 「전문가 모드에서 더 알 수 있는 것」 상자: 카드별 2가지(실제 설정 항목 기준) + 막힌 단계가 있으면 「막힌 단계 n개를 직접 열어 이유 보기」. 「이 답을 전문가 모드로 열기 →」(이전 「근거 사슬 그림으로 보기」 대체).
- API: /api/easy/answer에 expert {hints, stuck} 추가. 시험 215개(신규 3: 화면 이름이 전문가 모드에 실제로 있는지 검사 포함).
