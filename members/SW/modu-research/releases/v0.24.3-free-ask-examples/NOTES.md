# v0.24.3-free-ask-examples — 직접 물어보기 예시 질문 · 회사 이름 낱말 새는 문제 수정

- 쉬운 화면 「직접 물어보기」 아래 예시 단추 5개: 실적·현금흐름 / 수급 엇갈림 / 환율 영향 / 변동성·국면 / 공시 뒤 반응. 고른 회사 이름이 들어간 질문이 칸에 채워짐(바로 조사하지 않음).

- 예시 5개가 의도한 목표(N01·N08·N06·N10·N12)를 잡는지 시험으로 고정. v0.25(공시 반응 사전) 변경이 들어간 easy.js 위에 덧붙임. 시험 231개(클라우드) + 장치 전체.
