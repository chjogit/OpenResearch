# v0.15-easy-ui — 쉬운 화면 1.0 (질문 → 답 → 근거) + 근거 영수증(C2) + 그때 vs 지금(C1)

화면 버전
- `/` = 쉬운 화면 1.0 (새로): 질문 홈(회사 검색·빠른 버튼·질문 카드 6개·직접 물어보기·기준 날짜) → 진행 표시 → 답 카드 → 근거 서랍
- `/expert` = 전문가 모드 (v0.14 노드 캔버스 그대로 + 「← 쉬운 화면」 링크, `#run=<id>`로 답의 근거 사슬 열기, `#map`으로 근거 지도)

기능
- 질문 카드 6개 = 고정 근거 사슬(mrn/easy.py plan): 요즘 무슨 일(T08·T06→N11·N12) · 주가·수급(T06·T07→N09·N10·N07·N08) · 실적(T01 또는 T11→N01) · 환율·금리(T01/T11→N05, T10→N06) · 대주주(T12(+T02)→N13) · 매출 조기 확인(T11·T10→N14, 두 기준 기업만). 근거 지도 개수표로 카드별 사용 가능 여부·이유 표시
- 답 카드: 첫 문장 = 결론이 아닌 정리(확인·계산·추정·모르는 것 건수), 배지 3종(자료로 확인/계산한 값/추정·가정 ← 값 종류 8종), 핵심 숫자(추정값은 숨기지 않고 먼저), 이 결과가 아닌 것(앱이 하지 않는 것)과 아직 모르는 것을 분리, 단계 코드는 이름으로 바꿔 표시
- 근거 서랍: 값 종류·계산 방법·원문 링크·기준 날짜·쓴 자료 지문(해시)
- C2 근거 영수증: 사슬 해시 + 기준시점 + 단계별 결과 해시(취합 단계 제외) → 영수증 번호. 검증 = 같은 사슬·같은 기준시점 재계산 후 대조, 영수증 변조 감지(사슬·번호). 결과 해시는 실행 번호와 무관하게 재현됨을 확인
- C1 그때 vs 지금: 같은 카드를 예전 날짜 장 마감 기준으로 다시 계산해 항목별 나란히 비교(그날 공개 전 자료는 섞이지 않음)
- 최근 본 답(브라우저 저장), 처음 안내 3장, 인쇄·PDF, 모바일 폭 대응
- 워크플로 문서에 meta(카드·회사, 계산에 쓰지 않음) 추가 — 기존 문서와 호환
