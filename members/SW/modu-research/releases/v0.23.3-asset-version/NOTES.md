# v0.23.3-asset-version — 예전 디자인이 남는 문제 해결 · 모드 이동 단추 강조

- 원인: 화면 HTML은 매번 새로 받지만(/·/expert no-store), /static의 CSS·JS는 브라우저가 기억해 둔 예전 것을 써서 새 HTML에 옛 디자인이 입혀짐(모드 띠가 글자만 보이던 현상).
- 해결: 서버가 화면 HTML을 보낼 때 /static/*.css·js 주소 뒤에 파일 수정 시각(?v=)을 붙임 → 파일이 바뀌면 브라우저가 자동으로 새로 받음. 앞으로 Ctrl+F5 없이도 반영.
- 모드 이동 단추를 「가는 곳의 색」으로: 전문가 모드의 「← 쉬운 화면으로」는 주황, 쉬운 화면의 「전문가 모드로 →」는 남색.
- 시험 216개(신규 1). 서버 파일 변경 → stop.cmd → start.cmd 필요(이번 한 번만 Ctrl+F5).
