## 카드 이름표 (카드 id → 화면 이름) — 엔진 v0.39.1 `short`

| 카드 id | 화면 이름 = 엔진 short (v0.39.1) | 이전 엔진 short (v1.2~v1.5) |
|---|---|---|
| events | 최근 주요 사건 | 요즘 공시·뉴스 |
| price | 주가 흐름·매매 주체 | 주가·수급 |
| earnings | 실적 요약 | 실적 |
| macro | 환율·금리 영향 | 환율·금리 |
| holders | 대주주·지분 변동 | 대주주·경영진 |
| relations | 함께 움직인 지표 | 함께 움직인 것 |
| forecasts | 증권사 실적 전망 | 증권사 전망 |
| edi | 주가 선반영 햇수 | 주가와 실적의 시차 |
| nowcast | 이번 분기 매출 조기 추정 | 매출 조기 확인 |
| attention | 관심도 추이 | 관심도 |
| reaction | 공시별 과거 주가 반응 | 공시 반응 |

- 엔진 v0.39.1을 붙이면 화면의 `CARD` 표와 엔진 `short`가 같아지므로, 화면은 엔진 `short`만 써도 됩니다(표를 남겨 두셔도 결과는 같음).

## 따로 정하지 않은 것 — PM 답
- 공시 숫자 카드(`card=filing`): 엔진 이름(「이 공시는 숫자로 무엇인가?」) 그대로 — 좋습니다. 이 카드의 엔진 `short`는 「공시 숫자」입니다(카드 목록에는 나오지 않음).
- 「내가 만든 질문」 카드, 과제(`/api/learn`의 `tasks[].short`): 엔진 값 그대로 — 좋습니다. 이름을 바꾸고 싶어지면 같은 방식(R 번호)으로 보내 주세요.
