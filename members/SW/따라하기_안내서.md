# 모두의리서치 따라하기 안내서 (0~5단계)

PM(SW)이 만든 모두의리서치 엔진을 **내 PC에서 처음부터 똑같이 돌려 보는** 안내서입니다.
- 필요한 것: Windows 10/11 PC 한 대, 인터넷, **본인 명의의** 한국투자증권 Open API 키와 DART OpenAPI 키
- 걸리는 시간: 처음 한 번 1~2시간(키 발급 기다리는 시간 제외)
- 공용 DB(Neon)에 접속하지 않아도 됩니다. 처음 자료는 **본인 키로 직접** 받습니다(3단계 「첫 채움」).

> **꼭 지킬 것 세 가지**
> 1. 키는 **내 PC의 `engine\local-env.cmd` 한 곳에만** 넣습니다. 저장소·채팅·메신저·화면 캡처에 남기지 않습니다. 캡처에 키가 찍혔다면 그 키는 바로 폐기하고 새로 받으세요.
> 2. 받은 자료(시세·수급·공시)는 **연구용**입니다. 한국투자증권 자료는 재배포 계약 전이라 다른 사람에게 파일로 넘기거나 공개 저장소에 올리지 않습니다.
> 3. 이 앱은 **조회만** 합니다. 주문 기능이 없고, 투자 권유 표현을 쓰지 않습니다.

## 0단계 — git 쉬운 설명과 코드 받기

**git은 「시간을 기억하는 공책」입니다.**
- 「여기까지 저장!」 할 때마다 공책 모습을 사진으로 찍어 둡니다. 이 사진 한 장이 **커밋(commit)** 이고, 사진마다 번호(예: `3c1ba03`)가 붙습니다.
- 공책은 두 곳에 있습니다. **내 PC(로컬)** 와 **GitHub의 공용 보관함(원격, `chjogit/OpenResearch`)**.
- 공용 보관함을 내 PC로 처음 복사해 오는 것이 **클론(clone)**, 내 PC 기록을 보관함에 넣는 것이 **푸시(push)** 입니다.
- 각자 연습장을 따로 씁니다. 깨끗한 본 공책은 **main**, 연습장은 **브랜치(branch)**(`sw`, `ch` …)입니다.
- 「제 연습장 내용을 본 공책에 옮겨 주세요」라는 부탁 쪽지가 **PR(Pull Request)** 이고, 쪽지마다 번호(#85, #86 …)가 붙습니다. 자동 채점(CI)을 통과하고 확인을 받으면 **머지(merge)** 해서 본 공책에 붙입니다.
- PR이 머지되기 전에 같은 연습장에 더 올리면, 그 내용이 열려 있는 PR에 자동으로 따라 붙습니다. 묶음을 나누고 싶으면 머지된 뒤에 올립니다.

**코드 받기 (따라 하기만 하면 됩니다)**
1. Git 설치: https://git-scm.com/download/win → 기본값으로 설치
2. 명령 프롬프트(cmd)를 열고:
   ```
   cd /d D:\
   git clone https://github.com/chjogit/OpenResearch.git
   ```
3. `D:\OpenResearch\members\SW\modu-research` 폴더를 **통째로 복사**해서 `D:\모두의리서치` 처럼 내 작업 폴더를 만듭니다.
   (공용 저장소 폴더 안에서 돌리면 자료 파일이 섞일 수 있어서, 작업 폴더를 따로 두는 것을 권합니다.)
   새 버전이 나오면 `git pull` 로 받은 뒤 다시 복사하면 됩니다. 이때 내 `engine\local-env.cmd` 와 `_sources` 폴더는 덮지 않도록 주의하세요.

작업 폴더 모양:
```
D:\모두의리서치\
  engine\      엔진(화면 포함) — setup.cmd · start.cmd · stop.cmd · local-env.example.cmd
  tools\       도구 — first_fill(첫 채움·매일 갱신) · price_refresh · flow_refresh · backup …
  releases\    버전별 변경 기록
  _sources\    (3단계에서 생김) 내 자료 사본 — 공유하지 않음
```

## 1단계 — 설치

| 무엇 | 어디서 | 확인 방법(cmd) |
|---|---|---|
| uv (파이썬 설치·관리 도구) | PowerShell에서 `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 \| iex"` | `uv --version` |
| Node.js LTS (22 이상) | https://nodejs.org → LTS 설치 | `node --version` |

설치 뒤 **cmd 창을 새로 열고** 위 확인 명령이 버전을 보여 주는지 봅니다.

그다음 `D:\모두의리서치\engine\setup.cmd` 를 더블클릭합니다.
- 파이썬 3.12 가상환경(`.venv`)을 만들고 필요한 패키지를 설치합니다(처음 몇 분).
- 「Setup done. Run start.cmd」가 나오면 성공입니다.
- (선택) `test.cmd` 를 실행하면 엔진 시험 약 600개가 돕니다. 자료가 아직 없어서 일부(30여 개)는 「건너뜀」으로 나오는 것이 정상입니다.

## 2단계 — 키 받기와 넣기

### 받을 키
| 키 | 어디서 | 쓰는 곳 |
|---|---|---|
| **KIS_APP_KEY · KIS_APP_SECRET** | 한국투자증권 계좌 개설 → 한국투자증권 홈페이지·앱에서 KIS Developers(Open API) 서비스 신청 → 앱키·앱시크릿 발급. **실전투자용 키**를 씁니다(모의투자용 키는 서버가 달라 시세 조회가 안 됨). 신청 화면은 바뀔 수 있으니 포털(https://apiportal.koreainvestment.com) 안내를 따르세요 | 시세·수급·지수 **조회만**(주문 코드 없음) |
| **DART_API_KEY** | DART OpenAPI(https://opendart.fss.or.kr) 회원가입 → 인증키 신청(40자) | 공시 목록·재무·지분 |
| (선택) Claude 등 AI 키 | 각 서비스 | 질문 정리·초안 문장(없어도 숫자 계산은 그대로) |

### 넣는 방법
1. `engine\local-env.example.cmd` 를 복사해서 이름을 `local-env.cmd` 로 바꿉니다(같은 폴더).
2. 메모장으로 `local-env.cmd` 를 열고 아래 세 줄을 **본인 값으로** 채웁니다(`rem` 은 붙이지 않음).
   ```
   set KIS_APP_KEY=여기에_앱키
   set KIS_APP_SECRET=여기에_앱시크릿
   set DART_API_KEY=여기에_DART_인증키
   ```
3. 저장합니다. 이 파일은 저장소에 올라가지 않도록 막혀 있습니다(`.gitignore`). 그래도 **다른 사람에게 보내거나 캡처하지 마세요.**

KIS 접근 토큰은 1분에 한 번만 받을 수 있습니다. 실행을 연달아 두 번 하면 「토큰을 받지 못했어요」가 나올 수 있는데, 1분 뒤 다시 하면 됩니다.

## 3단계 — 첫 채움 (처음 자료 받기)

`tools\first_fill\첫채움.bat` 를 더블클릭합니다.

- 기본 **20개 회사**(코스피 큰 회사, 업종 고르게)의 자료를 본인 키로 받아 `_sources\neon\<시각>\` 에 사본을 만듭니다. 보통 5~10분 걸립니다.
- 회사별로 이런 줄이 이어지면 정상입니다.
  ```
  1/20 005930 삼성전자: 시세 370 · 수급 30 · 공시 250 · 재무 180
  ```
- 마지막에 「새 사본 … 를 만들고 LATEST 를 정했어요」가 나오면 끝입니다.

**받는 것과 비워 두는 것**
| 받는 것(본인 키) | 기간 |
|---|---|
| 회사 이름·시장·업종·상장주식수 | 오늘 |
| 일별 시세(원주가)·거래량·시가총액 | 약 1년 반 |
| 투자자별 순매수(개인·외국인·기관) | **최근 약 30거래일**(KIS가 주는 만큼) |
| 코스피·코스닥 지수 | 약 1년 반 |
| 공시 목록 | 2년 |
| 주요 재무 14계정(매출·영업이익·순이익·자산·부채·자본 등) | 사업보고서 5년 + 분기·반기 2년 |
| 최대주주·대량보유(5%) 보고 | 최근 3년 |

비워 두는 것: 뉴스·검색량·감성, 대차잔고, 공시 민감도(환율·금리), 비교기업, 거시지표. 이 칸은 화면에서 「자료 없음」으로 나오고, 나머지 기능은 그대로 동작합니다.

**정직하게 처리하는 것 두 가지**
- **외국인 보유율:** KIS 일자별 값은 「소진율(한도 대비)」이라, 통신·전력·항공처럼 외국인 한도가 있는 종목에서는 보유율과 다릅니다. 그런 회사는 보유율을 **비워 둡니다**(추정해서 넣지 않음). 끝에 「보유율을 비운 회사」로 알려 줍니다.
- **시가총액:** 오늘 상장주식수 × 그날 종가로 계산합니다(그 사이 주식 수가 같다는 가정). 이 가정은 사본 목록(`manifest.json`)에 적혀 있습니다.

**바꿔 쓰는 법** (cmd에서 `tools\first_fill` 폴더로 가서 `첫채움.bat 옵션`)
| 옵션 | 뜻 |
|---|---|
| `--check` | 키·폴더만 확인하고 끝냄(호출 없음). 처음엔 이걸로 키를 먼저 확인해 보세요 |
| `--tickers 005930,000660` | 회사를 직접 고름(6자리 종목코드, 쉼표로) |
| `--tickers-file 내목록.txt` | 한 줄에 종목코드 하나씩 적은 파일 |
| `--dry` | 받기만 하고 아무것도 쓰지 않음 |
| `--new` | 이미 사본이 있어도 새로 만듦(예전 사본은 지우지 않고 `LATEST.txt` 만 바뀜) |

**안전장치:** 이미 자료 사본이 있으면 덮지 않고 멈춥니다. 되돌리기는 `_sources\neon\LATEST.txt` 안의 이름을 예전 사본 이름으로 바꾸면 됩니다.

## 4단계 — 화면 켜기

1. `engine\start.cmd` 를 더블클릭하면 브라우저에 `http://127.0.0.1:4395` 가 열립니다.
2. 회사 이름(예: 삼성전자)을 고르고 카드 하나를 눌러 봅니다. 추천 순서:
   - 「주가 흐름과 누가 샀나?」 — 시세·수급
   - 「실적은 어땠나?」 — 재무(삼성전자·SK하이닉스는 공식 원문, 다른 회사는 공시 API 재무)
   - 「대주주는 누구고 바뀌었나?」 — 최대주주·대량보유
3. 결과의 모든 숫자에는 「근거 ›」가 붙어 있습니다. 눌러서 어느 자료의 몇째 줄인지 확인할 수 있습니다.
4. 끄기: `engine\stop.cmd`

**처음엔 이렇게 보이는 것이 정상입니다**
- 「가격과 수급을 함께 보는」 항목(N08)은 「함께 있는 거래일이 40일 이상 필요」로 보류됩니다. 수급이 30거래일뿐이라서입니다. 5단계 매일 갱신을 **약 2주** 하면 자동으로 풀립니다.
- 뉴스·대차잔고·비교기업·거시 관련 항목은 「자료 없음」입니다(3단계 표 참고).
- 장 마감(15시 30분) 전에는 전날까지의 자료로 답합니다.

이 화면은 엔진에 들어 있는 **전문가 모드 화면**입니다. 시연용 큰 화면(Django, 전태님 작업)은 따로 있습니다.

## 5단계 — 매일 갱신

장 마감 뒤(**16시 이후**)에 `tools\first_fill\매일갱신.bat` 를 더블클릭합니다.
- [1/2] 가격: 사본의 최근 5거래일 종가가 KIS 값과 **원 단위까지 같은지** 먼저 대조하고, 같을 때만 빈 날을 채웁니다.
- [2/2] 수급: 최근 5거래일 순매수 3종·거래량이 **주 단위까지 같은지** 대조하고 채웁니다.
- 어느 쪽이든 대조에 실패한 회사가 20%를 넘으면 아무것도 바꾸지 않습니다(응답 형식이 바뀌었을 수 있음).
- 매번 새 사본 폴더를 만들고 `LATEST.txt` 만 바꿉니다. 예전 사본은 그대로 남습니다.
- 이미 최신이면 KIS를 부르지 않고 바로 끝납니다.

**하루 이상 빠져도 괜찮습니다.** KIS가 수급은 약 30거래일, 시세는 더 길게 주기 때문에 그 안에만 다시 돌리면 빈 날이 채워집니다. 수급을 30거래일 넘게 비우면 대조할 겹치는 날이 없어 그 회사는 채우지 못합니다. 그때는 `첫채움.bat --new` 로 새로 받으세요.

**백업(선택):** `_sources` 폴더를 통째로 다른 드라이브나 내 클라우드에 복사해 두면 됩니다. 공유 폴더에는 두지 마세요.

## 문제가 생기면

| 보이는 글 | 뜻과 할 일 |
|---|---|
| `uv is required` / `Node.js is required` | 1단계 설치를 하고 cmd 창을 새로 연 뒤 다시 |
| `엔진 설치가 아직 안 됐어요` | `engine\setup.cmd` 먼저 |
| `키가 없어요: …` | 2단계. `local-env.cmd` 이름·위치(`engine` 폴더)와 `set 이름=값` 모양 확인 |
| `KIS 접근 토큰을 받지 못했어요` | 1분 뒤 다시. 계속되면 앱키·시크릿 확인 |
| `DART 010` / `DART 011` | DART 키가 틀렸거나 아직 사용 승인 전 |
| `DART 020` | DART 하루 호출 한도 초과 — 다음 날 다시 |
| `이미 자료 사본이 있어요` | 정상(덮지 않음). 최신화는 5단계, 새로 받기는 `--new` |
| `대조 실패가 …20%를 넘어` | 아무것도 바뀌지 않았습니다. 결과 파일(`last-result.txt`)을 PM에게 보여 주세요 — **키는 지우고** |
| 화면에서 「사본 … 해시가 다릅니다」 | `_sources` 안 파일을 손으로 고쳤거나 복사 중 깨짐. `LATEST.txt` 를 예전 사본으로 되돌리거나 `--new` |

도움을 청할 때는 `tools\first_fill\last-result.txt` 나 화면 글을 보내 주세요. 그 파일에는 키가 들어가지 않습니다.
