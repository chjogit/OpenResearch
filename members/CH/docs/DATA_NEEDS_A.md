# A안: 미확인 항목을 채우는 데 필요한 데이터 (에이전트 1·3)

2026-10-28 삼성전자 실행에서 에이전트가 "미확인"으로 남긴 항목을 채우려면 무엇을 더 모아야 하는지 정리한 목록입니다.
분류는 데이터 계약 r4-1.1의 `unverified[].availability`와 같습니다(`ch_agents/availability.py`).
수집은 kic-agent-data에서 하고, CH 에이전트는 DB 값만 씁니다. OpenDART 엔드포인트 이름은 구현할 때 공식 개발가이드로 다시 확인합니다.

## 4. 권장 순서

1. **A4·A5** (정형 API, 쉬움): 에이전트 5와 같이 씀.
