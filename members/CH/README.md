# CH 작업 폴더

CH 의 개인 작업 공간입니다. 실험 노트북, 스크립트, 메모를 자유롭게 두세요.

- 팀이 함께 쓸 코드가 되면 `agent/` 로 옮겨 PR 로 올립니다.
- `.env`, API 키, DB 접속 주소는 여기에도 커밋하지 않습니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `ch_agents/` | CH 담당 에이전트 패키지 (A1 거시·민감도, A4 투자심리·수급). `financial.py`(A2 재무)는 10/27 팀원 이관 후 참고용 |
| `ch_agents_A1_A2_A4.ipynb` | 위 패키지를 실행·확인하는 노트북 (데이터 확인 → 교차 검증 → 에이전트 실행 → 첨삭 → 일괄 점검) |
| `tests/` | 패키지 테스트. DB·LLM 없이 실행 |
| `solar_pro_4.ipynb` | 6+1 전체 파이프라인 원본. 참고용이며 더 이상 수정하지 않음 |

## 실행 (Windows cmd)

```
cd OpenResearch
pip install -r requirements-dev.txt
python -m pytest members\CH\tests -q
```

노트북은 `members\CH` 폴더에서 열고, `.env`에 `DATABASE_URL`, `UPSTAGE_API_KEY`를 둡니다.

## 출력 계약 (오케스트레이터 전달용)

`run_agent()`가 돌려주는 dict 키입니다.

| 키 | 내용 |
| --- | --- |
| `agent_id`, `agent_name`, `status` | 상태: 완료 / 완료 (수정 1회) / 완료 (일부 문장 제외) / 규칙 기반 대체 |
| `period`, `as_of` | 관측 기간과 기준일 |
| `result` | 핵심진단, 주장(문장·구분·근거 키), 긍정요인, 리스크요인, 미확인, 다음점검, 자체점수, 점수이유 |
| `facts`, `gaps`, `flags` | 숫자 장부, 무자료 목록, 코드 판정 |
| `checks`, `removed`, `attempts` | 코드 검사 결과, 최종 출력에서 뺀 문장, LLM 시도 기록 |
| `analysis`, `source` | 사람이 읽는 마크다운(키를 값으로 바꾼 것), 출처 |
| `docs` | RAG로 고른 참고 문서 목록 (`D1`부터 순서대로). 공시는 `kind="공시"` |
| `verification` | Verifier 대조 기록: 문장, ok, unmatched(맞지 않은 숫자), sources(출처 태그) |
| `exposure` | A1 노출 점검표 행: 변수, 등급(높음/중간/낮음), 근거, 전달 경로 |
| `anomalies` | A4 이상 징후 판정 문장 |
| `quality` | 데이터 품질 주의 원천 (quality.api_status 기준) |

`result`의 문장은 숫자 대신 `{M1}` 같은 키를 담고 있습니다. 값은 `facts[키]["text"]`로 바꿔 씁니다.

## DB 기반 RAG (`ch_agents/rag.py`)

6개 관점 모두 프리셋이 있습니다. A1·A2·A4는 자동으로 붙고, 팀원은 아래처럼 바로 씁니다.

```python
from ch_agents.rag import retrieve, docs_for_prompt
docs = retrieve(6, "005930", as_of="2026-10-26")   # 관점 번호 1~6
prompt_block = docs_for_prompt(docs)                # 프롬프트에 붙일 D1, D2 ... 목록
```

| 관점 | 문서 | 공시 유형 |
| --- | --- | --- |
| A1 거시 | 뉴스 30일 (환율·금리·관세·수출·물가·유가) | 없음 |
| A2 재무 | 뉴스 45일 (실적·배당·자사주·부채·신용등급) | 잠정실적·감사보고서·배당·자기주식·유상증자 등 1년 |
| A3 산업 | 뉴스 60일 (점유율·수주·증설·판가·규제) | 공급계약·시설투자·지분취득·합병 등 1년 |
| A4 수급 | 뉴스+블로그·카페·댓글 20일 (외국인·기관·공매도·심리) | 풍문 해명·조회공시·전환권 행사 120일 |
| A5 기술적 | 뉴스+블로그·카페·댓글 20일 (신고가·이평선·거래량) | 없음 |
| A6 대주주 | 뉴스 60일 (최대주주·경영권·지배구조·승계·행동주의) | 최대주주 지분 변동·지배구조·주총·소송 등 1년 |

- 검색: SQL로 종목·기간·출처를 좁혀 용어 일치 후보를 뽑고, 파이썬이 점수(용어 가중치 × 제목/요약 × 출처 × 최신성)를 매깁니다.
- 거르기: 종목명이 없는 문서, 사진 기사, 비슷한 제목, 출처별 개수 초과.
- 규칙: 문서 속 숫자는 쓰지 않습니다(코드 검사가 지움). 개인 의견 문서만으로는 '사실' 주장을 못 합니다.
- 한계: 공시는 제목만 있습니다(본문 없음). 벡터 검색은 `rag.chunk`가 비어 있어 아직 쓰지 않습니다.

## 기초기획서 R2 대응 (A1·A4)

| 기획서 요구 | 구현 |
| --- | --- |
| A1 입력: 관심 거시 변수 | `run_agent(1, ticker, focus=["환율", "금리"])`, `run_my_agents(..., focus=...)` |
| A1 기업 노출도 (규칙 기반 우선, LLM은 해석만) | `exposure.py`: ① 회사 공시값(사업보고서 원문 표: 환율 민감도 ÷ 영업이익, 수출 비중) → 없으면 업종 기본값 ② 주가 동조성(유의·|상관|≥0.3이면 상향) ③ 부채비율(금리). 달러 순자산·외환 파생 사용은 근거로 표시 |
| A4 입력: 기간 | `run_agent(4, ticker, period=10)` (거래일, 5~120) |
| A4 이상 징후 | 외국인·기관 최근 5일 순매수 강도의 표준점수 \|z\|≥2, 감성 변화 ≥0.15, 검색 관심 2배↑, 대차잔고 20일 +20%↑ |
| A4 심리·수급 요약표 | 코드가 만든 표 (계열·지표·값·코드 판정) |
| Verifier 통과 필수 | `verify.py`가 팀 공용 `agent/verifier/fact_source_verifier.py`로 최종 문장 수치 1:1 대조, 주장마다 `[출처: ...]` |
| 프롬프트 expert.md / guide.md 분기 | `ch_agents/prompts/expert.md`, `guide.md` (공통 + A1 + A4 절) |
| 품질 플래그 참고 | `quality.py`: quality.api_status 연속 실패·48시간 무성공·한도 도달이면 '데이터 품질 주의' |

한계: 회사 공시값은 kic-agent-data `report-exposure`가 사업보고서 원문 표를 찾은 회사만 있습니다(못 찾으면 업종 기본값). 헤지 효과는 수치로 반영하지 않습니다. 감성은 키워드 사전(FinBERT 점수는 DB에 없음).
